# Edit one sheet

Edit vocabulary_master.csv and save as CSV UTF-8. In Unity, exit Play mode and choose Lemko > Content > Import master vocabulary.

Keep established IDs unchanged. Activity pools and rules are edited in Unity's Inspector, not separate spreadsheets. New words must be assigned to the relevant activity. Removing a CSV row does not delete an asset or its gameplay references.

Other tables are historical copies in Archive/BeforeSingleMaster; normal imports do not use them. See Docs/MASTER_VOCABULARY.md for the current workflow.
